# Aster Labs — Data Handling Policy

This is a fictional sample document supplied with EvidenceLens.

## Storage and access
Research documents remain on the machine running the pilot. Access is limited
to approved participants. Documents containing customer payment details must
not be uploaded to the pilot.

## Retention
Operational audit logs are retained for 30 days. Source documents are retained
until the pilot ends, then removed unless a project owner approves an extension.

## Exceptions
Security exceptions require written approval from the security lead, Priya Shah.
The pilot owner cannot approve security exceptions on their own.

## External services
Sending document text to an external AI provider requires a separate review
and explicit approval before it is enabled.
